Slop Filter — Interests & settings

Works on X and LinkedIn. Interests, excluded topics and the API key are shared; strictness and length limits are set per platform.

API provider & key

Both providers run TypeSafe's Jev model through the same System One API, so the answers and thresholds are the same. OpenRouter bills your OpenRouter credits; TypeSafe bills a TypeSafe account.

Get a key at . It is stored only in this browser profile (chrome.storage.local, separate from the other settings) and sent only to .

The thresholds are fitted to Jev 1.13. jev-latest follows new releases; pin a version () to freeze the scale.

Interests

One per line, shared across both platforms. Posts substantively about any of these get highlighted (unless they are slop). Be concrete: "agentic AI tooling for developers" works better than "AI". Max 20.

Excluded topics

Posts whose main thrust matches any of these are hidden regardless of quality. Describe the thing literally — an attitude works too: "hostility toward AI and automation", "crypto and token launches".

Never filter these accounts

One X handle per line, with or without the @. These posts are never sent to the API and never hidden — useful for friends, and for anyone whose voice trips the "machine-sounding prose" signal. X only: LinkedIn's feed markup carries no stable handle to match on.

Per platform

X

X posts are short — a measured timeline had a median of 206 characters and a 10th percentile of 31. Raising the minimum is the cheapest way to cut both false positives and cost.

LinkedIn

Both go by LinkedIn's own label and are never sent to the API, so they cost nothing. Excluded topics cannot do this: they judge the post's text, and the label is not part of it.

LinkedIn posts are long by default, so the minimum sits higher and the battery includes a "no specific content at all" question that X deliberately omits.

AI style

A second score, separate from slop: does the post read as machine-written? It combines a dash count done in code with four questions to Jev (contrast punchlines, "not X, but Y" figures, inflated significance, templated section labels). No single Jev pattern flags a post; it takes several together. Em dashes are the exception: three or more flag a post on their own, one does not. The slop score and its thresholds are unaffected.

The four questions add about a third to the input tokens per post. The weights are first guesses: watch the badge for a while before switching to blur. AI style never hides a post outright.

Presentation

How it decides

Each post goes to TypeSafe's Jev model (directly or via OpenRouter) in one request carrying: a holistic Choice asking simply whether the post is slop, a battery of narrow yes/no questions (engagement bait, machine-generated prose, rage bait, selling, self-promotion, empty wisdom, recycled content, plus platform-specific ones), a graded “substance” score, and one question per interest and excluded topic. Questions are evaluated in parallel against the same post, so adding one costs its own tokens and almost no latency.

The holistic Choice leads the score because it separates far better than the battery does — measured on 25 labelled posts, a gap of 0.31 against 0.05. The battery stays because it is the only thing that can say which signal fired, which is how every false positive so far has been diagnosed and fixed. Code also computes the counting-based tells itself (thread numbering, emoji bullets, staccato line breaks, hashtag spam), because the model counts badly and a regex counts exactly.

What leaves your browser

The text of every evaluated post is sent to the selected provider: openrouter.ai, which forwards it to TypeSafe, or api.typesafe.ai directly. That includes posts from private connections and members-only groups. Nothing else goes anywhere: no engagement counts, no author names, no browsing history, and there is no server belonging to this extension. Answers are cached in this browser for the session so the same post is not sent twice.

Posts are not sent when they are promoted, a reply (if that is enabled), from an allowlisted handle, or shorter than the platform's minimum length. See TypeSafe's terms and data handling and OpenRouter's privacy policy for what they do with a request.

Roughly 3,000–3,500 input tokens per post, about $0.00014 at current prices, billed to your own key. With OpenRouter the popup shows the exact cost it reports. Moving the strictness slider re-scores cached answers, so it costs nothing.
